# Bridge changes

Base: embedded MCP for Unity 10.0.0 from Beach-Tank, with the user's documented WebSocket cancellation patch. Original source SHA-256 values are in vendor-provenance.json. License is MIT (CoplayDev, 2025).

1. Namespace/assembly prefix MCPForUnity → UnityCompatVendor; package name → com.unitycompat.cli, isolated preference keys, CLI-specific package metadata.
2. Disabled InitializeOnLoad hooks except tool caches, project identity, console log recording, test state and asset-generation job state. Disabled legacy MenuItem entrypoints and forced StdioBridgeHost auto-start false.
3. Kept dormant supporting implementations to avoid rewriting tool dependencies. Legacy networking is not the mailbox transport.
4. Qualified CodeDOM CompilerError to avoid a collision when compiling against complete Unity/.NET reference sets.
5. Added UnityCompat.Editor assembly: mailbox, extensible command registry, result normalization/Unity serializers, batch, polling and project/game commands.
6. Added dependencies for Audio, AI, Terrain, TerrainPhysics, AssetBundle, ParticleSystem and IMGUI modules used by the new commands.
7. Added server-free CLI, pip distribution, installation backup/rollback, Unicode handling, timeout/job protocols and tests.

`scripts/vendor_mcp.py` reproduces the initial import from a local v10 package; it refuses to overwrite the developed bridge. Subsequent compatibility code and patches are maintained in Git, not re-generated by vendoring. `scripts/build_catalog.py` rebuilds the inventory from the maintained source.

Version 0.2 adds a Windows NativeAOT caller, authenticated same-user named pipes, shared main-thread dispatch and persistent job records. It adds five bounded Agent queries/edits, ordinary command files and compact payload output. The file mailbox remains the Python compatibility route; no automatic replay occurs after a transport failure. The Windows pipe ACL uses a Win32 token SID because Unity's Mono does not implement the required WindowsIdentity properties.

Version 0.3 adds a persistent eight-connection client pool, authenticated idle
keepalive, optional detached native daemon, native MCP stdio, method CliCommand/
parameter CliArg schemas, deep projection, and independently relocated Roslyn eval.
Editor dispatch drains a bounded burst and briefly wakes the Editor without
permanent busy polling. TestJobManager delays starting Test Runner by 250ms so the
caller receives the job ID before a possible domain reload; native test only polls
that same ID afterward. Script creation no longer overwrites a concurrent creator
when atomic File.Move fails. Additional wrappers replace Python-server helpers;
native frontend interfaces cover session management and official documentation.
